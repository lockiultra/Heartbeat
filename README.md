# Heartbeat

AI Copilot for doctors. This repository currently contains only the initial project bootstrap and directory layout.

## Prerequisites

- Python 3.13
- `uv`

## Installation

```bash
uv sync
```

## Project Structure

```text
.
├── backend/
│   ├── src/
│   │   └── app/
│   │       └── __init__.py
│   └── tests/
├── docs/
├── frontend/
├── infra/
└── scripts/
```
